# Fuentes de imagen

Todos los medios que consume Remotion están en `public/`.

`capture-manifest.json`: siete screenshots nuevas capturadas el 30/10/2026 por Playwright. UI real a 1000×1250 CSS px con deviceScaleFactor=2: imágenes de 2000×2500. Capa de datos: servicios locales de la demo existente, sin mock de API ni manipulación de UI. No se guardaron consultas nuevas ni se aplicaron cambios de configuración. La ficha y la consulta muestran registros ficticios de la demo.

La captura `encounter.png` contiene una frase DEMO tipeada en un formulario sin guardar, no incorporada al video. `detail.png`, que sí aparece, muestra una consulta guardada previamente en la demo. El nombre «Tutorial Ficticio» pertenece al dataset real de prueba; no implica que esta pieza sea un tutorial.

No se usa ninguna captura grabada del tutorial en el reel, ni voces ni clips de su edición. Todo el movimiento de producto es cámara digital sobre las imágenes nuevas; se renderiza a 60 FPS. El logo y la tipografía se copiaron sin redibujar de DoctorChart; licencia de fuente en `public/fonts/OFL.txt`.
